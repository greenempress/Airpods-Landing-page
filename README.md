# 🎧 AirPods Product Landing Page  

A clean, minimal, and responsive **product landing page** showcasing different AirPods models, their features, and pricing — inspired by Apple’s sleek design aesthetic.  
This project was created to practice layout composition, product presentation, and responsive design techniques using **HTML**, **CSS**, and a little **JavaScript**.  


## 🌐 Live Demo  
👉 [View the Live Site](https://airpods-landing-page.vercel.app/)  


## 💡 About This Project  
The goal of this project was to design a landing page that feels **modern, simple, and premium** — consistent with Apple’s visual identity.  

I focused on:
- Balancing white space and typography for a high-end feel  
- Structuring sections for intuitive product flow (features → pricing → CTA)  
- Keeping color contrast minimal and product-focused  
- Writing clean, organized code that’s easy to update and expand  


## ✨ Features  
- 🖥️ **Responsive design** that adapts to all screen sizes  
- 🎨 **Apple-inspired aesthetic** using soft gradients and subtle shadows  
- ⚙️ **Interactive hover effects** for buttons and product cards  
- 🧩 **Organized HTML, CSS, and JavaScript** for scalability and readability  


## 🛠️ Built With  
- **HTML5**  
- **CSS3 / Flexbox & Grid**  
- **JavaScript**  


## 🧠 Lessons Learned  
This project helped me:
- Strengthen my understanding of **responsive layout design**  
- Practice **consistency in branding and spacing**  
- Experiment with **clean animations and subtle UI effects**  
- Refine **project structuring** for readability and future edits
